# Store listing — draft for review

Every field is inside its store's limit. The counts below were computed by the

## Decisions for you before this is final

- **Store name.** Drafted as **Loay Motawie** to match loaymotawie.com. The app
  currently shows **LoayMohamed** under its home-screen icon. Pick one and use it
  in both places, since a mismatch looks careless to reviewers and students.
  Other options: *Loay Motawie Maths* (18 characters), *Loay Mohamed E-Learning* (23).
- **Subject.** The subtitle and keywords assume **maths** (the lessons I saw were
  Edexcel maths). Change them if your classes cover other subjects.
- **Arabic listing.** Only English so far. An Arabic version can be added
  alongside it.

## What the description deliberately does not claim

It only lists things I have seen working in the app. It does not mention
offline viewing, downloads or live classes, because the app has none of them.
Claiming a feature the reviewer cannot find is a rejection under Apple
guideline 2.3.1.
